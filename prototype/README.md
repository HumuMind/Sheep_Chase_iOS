# 可点击原型

直接打开 `index.html` 即可，无需构建。建议用 Chrome / Safari，窗口宽度 1280 以上。

## 主流程

1. **我的开团**：点击任一开团卡片进入工作区。
2. **场景**：左栏切换场景/节拍，中间看朗读、遭遇和分支；右栏切换队伍、先攻、速查、笔记。
3. **战斗筹备**：顶部切到「战斗」，或用遭遇卡的「筹备战斗」。中间逐个选择参战玩家、逐个添加怪物；App 按人数/平均等级给建议，但不会自动加入。点「下一步：填写先攻」后，玩家自己掷先攻、DM 填结果；怪物先攻由 App 自动掷（d20 + 加值），不需要填写。玩家都填完后开始战斗，进入轮次。
4. **切换开团**：带团中点「我的开团」或「切换开团」，若战斗未结束会先弹确认。
5. **新建开团**：完全空白，队伍需要手动录入；在右侧「队伍」点「＋ 添加玩家」，填姓名、等级、AC、HP、先攻加值、被动感知。
6. **地图**：点图钉看房间提示；「导出 / 分享原图」演示 B9 的干净原图导出。
7. **便签**：右侧「笔记」页签是多张便签，可新建、换颜色、删除；每张独立保存。
8. **遮屏**：顶栏「遮屏」或 `Esc` 恢复，用于临时挡住 DM 秘密。

> 队伍面板带等级（Lv），并支持「＋ 添加玩家」；它仍不是角色卡，只记录战斗需要的最小数值。玩家先攻由玩家自己掷、DM 填写；怪物先攻由 App 自动掷 d20 + 先攻加值。

## 直接打开某个视图

在 URL 后加 hash：

- `#library` 开团库
- `#run` 场景工作区
- `#combat` 战斗筹备（未填写先攻）
- `#fight` 直接查看战斗态（演示数据；实际流程需先填写先攻）
- `#map` 地图
- `#npc` NPC 扮演卡
- `#export` 图片导出
- `#new-run` 新建开团
- `#privacy` 遮屏

## 快捷键

- `N`：开始战斗后，下一回合
- `Esc`：关闭弹层 / 恢复遮屏
- `⌘K`：占位提示（全局搜索尚未接入）

## 说明

- 数据是原型样例，不会写回 `content/`。
- 没有真实持久化、系统保存面板或分享面板；这些留给 SwiftUI 实现。
- 目标是验证信息架构和主流程，不是最终视觉定稿。
